Framework help

Choose an integration without lock-in

The same core assets work with plain HTML, server-rendered WordPress templates or a separate frontend that reads WordPress over REST.

Standalone

Load dist/win2k-ui.css and dist/win2k-ui.js, then write semantic HTML using the Win2k UI classes. Your application owns routing, content and persistence.

<link rel="stylesheet" href="win2k-ui.css">
<div class="win2k-app" data-win2k-app>…</div>
<script src="win2k-ui.js" defer></script>
WordPress theme

Install the optional block theme. It loads the same core and maps WordPress templates, navigation and editor patterns to Win2k UI presentation.

Install the content plugin only if the website needs portable Project records.

Download themeDownload content pluginInstallation guide
Headless WordPress

Keep this standalone frontend and use the REST adapter to read public pages, posts or projects from WordPress. This is optional and requires additional production work for authentication, previews, cache and SEO.

Responsibility boundaries
  • Core: visual system and generic interactions.
  • Theme: presentation and WordPress templates.
  • Plugin: durable content types and functionality.
  • Host application: authentication, business rules and storage.
