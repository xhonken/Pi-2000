# English interface and Pi-2000 naming

The desktop UI, accessible names, dialogs, installer messages and shared project
documentation use English. External websites and user-authored content retain
their own language. File and Edit use Alt+F and Alt+E; locale formatting is en-GB.

The product is Pi-2000. Applications include Pi-IPTV, Pi-Vault, Pi-Arduino,
Pi-Calt, Pi-DB Manager, Pi-API and Pi-Git Projects. Familiar names such as My
Computer, My Files and Task Manager remain. Personal labels are never translated.

Alpha 8 uses Pi-2000 identifiers throughout the maintained application. This is
the independent 0.2 data line, with no compatibility import from earlier releases.
See [system names and installation boundaries](../SYSTEM-NAMES.md).

The earlier branding review, language-change evidence and gallery provenance
remain in the [Alpha 7 source tree](https://github.com/xhonken/Pi-2000/tree/v0.1.0-alpha.7/docs).
Current screenshots use disposable demonstration data, never private sessions.
