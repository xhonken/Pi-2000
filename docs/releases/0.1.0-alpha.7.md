# Pi-2000 0.1.0-alpha.7

Alpha 7 consolidates Pi-2000 naming, fixes logout failures and removes obsolete
code. The Python/aiohttp and plain JavaScript desktop, private user data and
Windows 2000-inspired appearance remain the foundation.

## Changes

- **Consistent application names:** Pi-2000, Pi-IPTV, Pi-Vault, Pi-Arduino,
  Pi-Calt, Pi-DB Manager, Pi-API and Pi-Git Projects. Familiar Windows-style
  names and personal icon labels remain unchanged.
- **System names:** `pi2000-*` services, account/group and process names, with
  canonical installation paths. The guarded source migration creates verified
  backups, preserves numeric ownership and rolls back caught activation errors.
  It checks running jobs and waits for API readiness before verification.
- **Logout:** workspace save conflicts and failed recovery no longer prevent
  an explicit sign-out. Saved checkpoints and application cancellation guards
  remain in place.
- **Cleanup:** removed 31 superseded reference-gallery files, obsolete pixel
  drawings, unused imports/state and an unused development dependency. Demo-only
  JavaScript is no longer installed in the public desktop. ZIP export avoids an
  unused full file-table read; My Activities stops making unused health requests.
  Icon generation now reproduces the current SVG assets, including Pi++/Pi-Vault.
- **Packaging and checks:** cached Python runtimes are rebuilt when installation
  paths or the interpreter change, so console scripts use the new namespace.
  The package version follows VERSION. CI sandbox and dynamic editor-mode checks
  include the fixes made after Alpha 6.

Pi-IPTV, Pi-Vault, workspace recovery, personal desktop controls, development
applications, PAM identities and private SSH connections remain included.
See the [cleanup review](https://github.com/xhonken/Pi-2000/blob/v0.1.0-alpha.7/docs/CODE-CLEANUP.md).

## Download and installation

Target: **Raspberry Pi OS 64-bit / Debian 13 (Trixie), arm64, Python 3.13**.
Debian 12, 32-bit systems and Intel/AMD package installation are not supported.

Download `pi2000web_0.1.0.alpha.7-1_arm64.deb` and `SHA256SUMS` from this release.
The internal Debian version is `0.1.0~alpha.7-1`; GitHub normalizes the filename.
For a fresh installation:

```sh
sha256sum --check SHA256SUMS
sudo apt install ./pi2000web_0.1.0.alpha.7-1_arm64.deb
sudo pi2000web doctor
```

The installer asks for a creator account/password and retains individual Linux
identities, private homes and PAM authentication. See the
[package guide](https://github.com/xhonken/Pi-2000/blob/v0.1.0-alpha.7/docs/DEB-INSTALLATION.md).

### Existing installations: read before upgrading

- **Source installation with old `win2k-*` names:** use the
  [system-name migration](https://github.com/xhonken/Pi-2000/blob/v0.1.0-alpha.7/docs/SYSTEM-NAMES.md).
  Save work and plan a service interruption. The migration preserves data and
  UID/GID, but cannot preserve running OS processes. Old directory links remain
  where existing virtual environments need compatibility.
- **Already migrated source installation:** use the source updater and doctor.
  Activate updated session/Arduino workers only after their jobs finish, following
  the [maintenance guide](https://github.com/xhonken/Pi-2000/blob/v0.1.0-alpha.7/docs/MAINTENANCE.md).
- **Alpha 6 or older Debian package with old names:** direct upgrade is blocked
  before unpacking. A package-managed namespace migration has not been validated.
  Do not bypass the guard, remove the package-management marker or use the source
  migrator on a dpkg-managed installation. This Alpha 7 package targets fresh
  installations; it is not an in-place migration for older packages.

Do not downgrade against newer live data or mix source and package management.

## Validation and remaining limits

The cleanup and namespace changes passed **194 backend tests, 27 ordinary browser
suites and 2 geometry suites**. The final IPTV stability suite ran separately
following an interrupted long local test run: a simulated 2.5-second network
outage produced zero stalls and zero catch-up seeks. Icon computed styles remained
identical, and the standalone demo still works after moving its script.

Installed Pi 5 validation covered the guarded migration, HTTPS, PAM, Local Terminal,
password-change revocation, backup, logout and four-account file/Vault/ZIP privacy.
The package is checked for metadata, build identity, deployment hashes, new-path
console scripts and checksums. The screenshot uses disposable accounts and
locally generated media.

**Fresh installation of this exact package on a reimaged Pi 4 remains pending.**
Installed Pi 5 source checks and earlier package tests do not replace that check.
Physical power-loss recovery and independent security/crypto review remain open.
Workspace checkpoints restore supported windows/drafts, not running OS processes.

The Browser app remains paused when installed Chromium is below the reviewed
security floor of **153.0.8010.52**. This does not disable Pi-IPTV in the client
browser and does not certify newer engines against future vulnerabilities.
Provider availability, bandwidth, codecs and archive support still constrain IPTV.
See the [security boundaries](https://github.com/xhonken/Pi-2000/blob/v0.1.0-alpha.7/docs/SECURITY.md).
