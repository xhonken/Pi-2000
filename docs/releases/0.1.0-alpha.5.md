# Pi-2000 0.1.0-alpha.5

Alpha 5 brings Arduino/ESP32 development, Pi++, five graphical tools and desktop
reliability fixes into a new arm64 Debian test installer.

## New applications and improvements

- **Arduino Workshop:** private multi-file projects, graphical board options,
  versioned board/library installation, library includes, import/export,
  compilation, Pi-connected USB upload and Serial Monitor. Missing catalogs are
  prepared automatically on first search. Arduino CLI runs in its own
  memory-limited, isolated service; USB access requires a web administrator.
- **Pi++:** Notepad++-inspired menus, compact toolbar, document navigation,
  accessible tabs, Save All, graphical open/import, search across documents,
  bookmarks, language and line-ending selection, and private preferences.
  Existing files, SFTP connections, conflict checks and recovery drafts remain.
- **Network Tools:** private targets, DNS/ping/TCP diagnostics and monitoring from
  the Pi, with result export.
- **Display Studio:** layers, shapes, text, images and round-display presets;
  editable private projects and PNG, RGB565 and Arduino header export.
- **Archive Manager:** ZIP creation, inspection and selected extraction into a
  new private folder, with path, expansion and quota checks.
- **Log Viewer:** bounded private-file and SSH/SFTP tails with filters and follow
  mode, retaining SSH host-key checks.
- **Serial Plotter:** Arduino Workshop → Tools; incremental input, up to eight
  curves, scaling, pause and CSV export, sharing Serial Monitor's USB controls.
- CAD-specific menu commands stay in Dimension Drawing. Large and restored
  windows keep title-bar controls on screen. Source updates reconcile missing
  declared native dependencies.

The existing PAM accounts, protected creator, private Linux homes and per-user
administrator Local Terminal remain. Web administration does not grant OS sudo.
The architecture review is included as documentation; its larger modularization
plan has not been implemented by this release.

## Download and test installation

Target: **Raspberry Pi OS 64-bit / Debian 13 (Trixie), arm64, Python 3.13**.
Debian 12, 32-bit systems and Intel/AMD are not supported by this package.

Download `pi2000web_0.1.0.alpha.5-1_arm64.deb` and `SHA256SUMS` from this release
into the same directory, then run:

```sh
sha256sum --check SHA256SUMS
sudo apt install ./pi2000web_0.1.0.alpha.5-1_arm64.deb
sudo pi2000web doctor
```

GitHub normalizes the filename's `~` to `.`; the internal Debian package version
is `0.1.0~alpha.5-1`. The package includes pinned Python runtimes and Arduino CLI;
APT installs native dependencies. Arduino board packages and libraries are
installed separately per account from the graphical package managers.

Use a dedicated test Pi for fresh installation. Setup asks for a protected creator
username and password, provisions a private initial MariaDB connection, and uses
Caddy's local CA for HTTPS by default. Trust only the public root certificate on
your client. See the [Debian installation guide](https://github.com/xhonken/Pi-2000/blob/v0.1.0-alpha.5/docs/DEB-INSTALLATION.md).

## Upgrading

1. Back up and finish database operations, Arduino builds/uploads and other live
   work. Disconnect Serial Monitor/Plotter.
2. For a package-managed host, install the new `.deb` with APT. Its upgrade script
   requires a verified local backup and preserves private data. API/PHP services
   restart; active session and Arduino workers can retain their old code.
3. Once jobs have finished, run `sudo pi2000web restart-sessions` and
   `sudo systemctl restart pi2000-arduino` to load the new worker code, then
   `sudo pi2000web doctor` and reload the desktop.
4. For a source-managed host, use the [source update guide](https://github.com/xhonken/Pi-2000/blob/v0.1.0-alpha.5/docs/INSTALLATION.md).
   The `.deb` deliberately refuses to overwrite an existing unmanaged source
   installation. Do not run the source updater on a package-managed host.

Legacy account migration occurs at successful login. Linux/web passwords and
MariaDB passwords remain separate. Do not downgrade against migrated live data;
review [account recovery](https://github.com/xhonken/Pi-2000/blob/v0.1.0-alpha.5/docs/SYSTEM-ACCOUNTS.md) before restoring.

## Validation and known gaps

Release preparation reran all **124 backend tests** successfully. Six isolated
browser suites passed: Arduino Workshop, Pi++, the five utility tools, window
placement, English UI and classic accessibility. These include real serial I/O
through a disposable PTY, disposable SSH/SFTP log reading, ZIP operations,
pixel/file-level display exports and narrow/large-font layouts.

Earlier implementation checks verified the additions on the installed Pi 5,
including private account boundaries, real ESP32/ArduinoJson compilation and
first-use Adafruit library installation. Those are recorded implementation tests,
not fresh installation of this release's `.deb`.

The release package is built and checked for metadata, exact application content,
clean source identity, bundled runtimes/CLI and checksums. It has **not yet passed
fresh installation or upgrade acceptance on a physical test Pi**. Earlier Pi 4
package lifecycle tests predate the final PAM migration and these applications.

Physical ESP32 flashing, plotting a real sensor and displaying an exported image
on a physical GC9A01A remain pending. ZIP support is Store/Deflate, not RAR/7z;
Pi++ does not implement Notepad++ plugins/macros. Arduino compilation and Browser
sessions can contend for memory on small Pis. Full OS-account restore still
requires manual UID/home reconciliation; linked OS homes/passwords are excluded
from platform backup. This is Alpha software, not long-duration or multi-user
load certification.

See the [user guide](https://github.com/xhonken/Pi-2000/blob/v0.1.0-alpha.5/docs/HELP.md)
and [changelog](https://github.com/xhonken/Pi-2000/blob/v0.1.0-alpha.5/CHANGELOG.md).
